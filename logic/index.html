Sinteza Capitolului 1: Numere Naturale

I. Adunarea Numerelor Naturale

Proprietăți:

  • Comutativitate: a + b = b + a
  • Asociativitate: a + (b + c) = (a + b) + c
  • Element neutru: 0 (a + 0 = 0 + a = a)

II. Scăderea Numerelor Naturale

Definiție: Diferența dintre a și b (a ≥ b) este numărul c, unde a = b + c.

Termeni: a - descăzut, b - scăzător, c - diferență.

III. Înmulțirea Numerelor Naturale

  • Comutativitate, Asociativitate.
  • Element neutru: 1 (a * 1 = a).
  • Distributivitate față de adunare/scădere: a * (b ± c) = a * b ± a * c

IV. Împărțirea Numerelor Naturale

Teorema împărțirii cu rest: D = Î * C + R, unde 0 ≤ R < Î

⚠️ Împărțirea la zero este imposibilă!

V. Puterea unui Număr Natural

Formula: an = a * a * ... * a (de n ori)

Cazuri speciale: a0 = 1 (a ≠ 0), 0n = 0, 1n = 1

VI. Ordinea Efectuării Operațiilor

  1. Puteri
  2. Înmulțiri și Împărțiri
  3. Adunări și Scăderi

Obs: Se lucrează de la stânga la dreapta pentru operații de același ordin.
