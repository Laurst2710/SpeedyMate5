Sinteza Capitolului 1: Numere Naturale

1. Sistemul Zecimal și Pozițional

Sistemul nostru este „zecimal” (grupăm unitățile câte zece) și „pozițional” (valoarea unei cifre este dată de locul ei: unități, zeci, sute).

2. Cifră vs. Număr

Cifrele sunt simbolurile de la 0 la 9 (alfabetul), iar numerele sunt cantitățile formate cu ele (cuvintele).

3. Succesor și Predecesor

Orice număr natural "n" are un succesor (n + 1) și, dacă este mai mare ca 0, un predecesor (n - 1).

4. Aproximări și Estimări

Folosim rotunjirea pentru a verifica rapid validitatea unui calcul.

  • Regulă: Dacă cifra următoare este 0, 1, 2, 3 sau 4, rotunjim prin lipsă (cifra rămâne la fel).
  • Regulă: Dacă este 5, 6, 7, 8 sau 9, rotunjim prin adaos (cifra crește cu 1).

5. Axa Numerelor

Fiecare număr are un punct unic pe axă. Distanța de la origine ne ajută să vizualizăm mărimea numerelor.

6. Proprietățile Adunării

  • Comutativitatea: a + b = b + a
  • Asociativitatea: (a + b) + c = a + (b + c)
  • Element Neutru: 0 (a + 0 = a)

7. Rigoarea Scăderii

În numere naturale, scăderea a - b este posibilă doar dacă a >= b.

Proba obligatorie: Diferență + Scăzător = Descăzut

8. Înmulțirea și Distributivitatea

Înmulțirea este o adunare repetată.

Distributivitatea față de adunare/scădere:
a * (b + c) = a * b + a * c

9. Tehnica Factorului Comun

Inversul distributivității. Identificăm factorul care se repetă și îl scoatem în fața parantezei.

Exemplu: 15 * 7 + 15 * 3 = 15 * (7 + 3)

10. Teorema Împărțirii cu Rest

D = Î * C + R, unde 0 <= R < Î

⚠️ Împărțirea la zero este interzisă!

11. Puterea cu Exponent Natural

Reprezintă o înmulțire repetată (an).

Reguli:
  • am * an = am+n
  • am : an = am-n
  • (am)n = am*n

12. Pătrate Perfecte și Sisteme de Bază

  • Pătrate perfecte: Numere ca 0, 1, 4, 9, 16.
  • Expert Tip: Un număr care se termină în 2, 3, 7 sau 8 NU este pătrat perfect.
  • Sisteme: Baza 10 (zecimal) și Baza 2 (binar - limbajul computerelor).

13. Ierarhia Calculului (Ordinea Operațiilor)

  1. Ordinul III: Puterile (primele).
  2. Ordinul II: Înmulțirea și Împărțirea.
  3. Ordinul I: Adunarea și Scăderile.

Paranteze: Lucrăm din interior spre exterior: ( ), apoi [ ], apoi { }.

Aceste 13 puncte reprezintă temelia succesului tău la matematică! 🚀
